Settings

Shortcut

Global toggle

Starts and stops dictation from any application.

Push to talk

Held down to dictate. Handled by the engine, so it works even when Sotto is not running in the foreground.

Model

Speech

Larger is more accurate and slower.

Language

Pinning one is faster and avoids misdetection on short clips.

Cleanup

Removes fillers and restores punctuation. Use a non-reasoning instruct model — reasoning models emit their working out as the answer.

Microphone

Avoid anything named loop-back — that is system audio, not your voice.

Application

Start with Windows

Launches Sotto at sign-in so dictation is available without opening anything.

Recording indicator

Floats a lamp and level meter above other windows while dictating, so you can see it is listening without switching to Sotto.

Speech engine

Started and stopped with the app. Nothing to run by hand.

—

Changing the speech model or microphone takes effect the next time the engine starts.
